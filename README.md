# הזמנות מירון

אתר ניהול לחברת הזמנות לבתי אירוח: הזמנות טלפוניות, בתים ויחידות, יומן תפוסה, מחירון, חשבוניות עמלה, הוצאות, משכורות, רווח והפסד.

אתר סטטי (HTML ו-JS) עם Supabase כמסד נתונים ומערכת כניסה. אין שלב בנייה.

## הקמה
1. ב-Supabase: SQL Editor, להריץ את `supabase/schema.sql`.
2. ב-Authentication: לכבות הרשמה עצמית (Allow new users to sign up), וליצור משתמשים ידנית.
3. להוסיף כל משתמש לטבלת `staff` (ראה הערה בסוף הסכמה).
4. למלא `config.js` בכתובת הפרויקט ובמפתח הציבורי (anon או publishable).
5. לחבר את המאגר ל-Vercel. כל דחיפה ל-main פורסת את האתר.

## מבנה
- `index.html` מעטפת ועיצוב
- `adapter.js` כניסה וחיבור למסד
- `app.js` האפליקציה
